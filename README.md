# coastal-shells

Zsh config with no framework: hand-picked plugins, a fast git prompt, aliases and functions, plus tmux window marks for finished commands, `(✓)` or `(✗)`.

Links the repo to `~/.config/zsh` and `~/.zshrc` to `zshrc-mac.zsh`.

## Install

```sh
git clone https://github.com/solomonxie/coastal-shells.git ~/myconf/coastal-shells
~/myconf/coastal-shells/install.sh
```

Anything already at a target path is moved to `<path>.bak.<timestamp>`.
